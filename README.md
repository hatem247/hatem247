### 🎓 Capstone Management System

A project and task management platform designed to support capstone teams, task assignments, submission reviews, deadlines, and structured resubmission workflows.

**Highlights:**
- Team-based task submission and tracking.
- Submission review and rejection workflows.
- Reopening rejected submissions with new deadlines.
- Sequential resubmissions with dedicated status indicators.
- Deadline-aware editing and resubmission handling.
- Team submission management and task status tracking.

**Technologies:** `ASP.NET Core` · `C#` · `SQL Server` · `REST APIs` · `Web Development`

**Repository:** Private team project.

### ⚖️ ElSewedy Judge System — Online Programming Judge

A web-based programming judge system integrating an ASP.NET Core backend with the **DMOJ judging engine** to support programming problems, submissions, and automated evaluation.

**Highlights:**
- Integration between the web application and judging engine.
- Problem package importing and ZIP processing.
- Submission filtering and judging-result verification.
- Development and testing of the judging adapter.
- Support for C, C++17, Python, Java, C#, Go, Rust, and Kotlin.

**Technologies:** `ASP.NET Core` · `C#` · `SQL Server` · `DMOJ Judge Server` · `Debian Linux`

**Repository:** Private team project.
